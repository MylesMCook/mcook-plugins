# Miller's Law

Source concept: https://lawsofux.com/millers-law/

## When to load

Load this reference when lists, menus, dashboards, form sections, onboarding steps, comparisons, or interfaces that ask users to remember multiple items.

## Lens

Working memory is limited; grouping information can make it easier to process, but the classic number should not be used as a rigid quota.

## Look for in the design

- long lists with no grouping or hierarchy
- navigation with too many top-level items
- design arguments that misuse '7 plus or minus 2' as a hard rule

## Critique moves

- Chunk items into meaningful groups instead of merely limiting count.
- Reduce memory burden by showing context, selections, and prior choices.
- Use hierarchy and summaries to help users process sets.

## Watch-out

Do not enforce arbitrary item limits when good grouping solves the actual problem. Miller's original paper addressed limits in specific immediate-memory and judgment tasks, not a navigation-item quota. Later work suggests smaller capacities under some conditions. See [Miller, 1956](https://psychclassics.yorku.ca/Miller/) and [Cowan, 2001](https://doi.org/10.1017/S0140525X01003922).
