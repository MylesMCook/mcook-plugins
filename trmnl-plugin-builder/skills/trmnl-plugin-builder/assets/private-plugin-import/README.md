# Sanitized import starter

These files are an offline starting point for a Private Plugin import archive.
Before upload, verify the current TRMNL import/export guide and copy only the
needed files into an empty directory so the ZIP root is flat.

Replace the example public endpoint and synthetic values with the approved
non-sensitive data contract. Do not add credentials, headers containing secrets,
webhook URLs, plugin identifiers, or real preview data. Importing or saving the
archive requires explicit approval.
