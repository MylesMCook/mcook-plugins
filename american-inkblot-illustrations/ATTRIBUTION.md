# Attribution

American Inkblot Illustrations is a US English localization and substantial
workflow expansion inspired by
[Ian Xiaohei Illustrations](https://github.com/helloianneo/ian-xiaohei-illustrations),
created by Ian and released under the MIT License.

The upstream project established the core visual idea: a small solid-black
worker, pure white 16:9 compositions, sparse hand-drawn line work, restrained
red/orange/blue notes, and one cognitive move per illustration. This derivative
renames the character to Inkblot for US-facing use, avoids racialized readings
and patriotic shorthand, and does not bundle or reproduce upstream example
images.

The bundled `inkblot-reference.png` is an original image generated for this
plugin with OpenAI image generation on 2026-07-21.

The earlier local `american-inkblot-illustrations` skill added the US English
editorial workflow. This plugin preserves that stable skill ID and adds an
evidence-grounded method for explaining software, services, agent systems,
automations, homelabs, and operational plumbing.
