# Changelog

## 0.2.2 - 2026-08-24

- Added the portable Agent Plugins 1.0.0 manifest while retaining the Codex
  compatibility overlay.

## 0.2.1 - 2026-07-21

- Prevent Inkblot-first prompts from using an oversized prop that visually
  demotes Inkblot.

## 0.2.0 - 2026-07-21

- Make Inkblot-first the default for general illustration requests: one
  Inkblot, a nearly empty canvas, few props, and no labels unless needed.
- Keep evidence-grounded system portraits as an explicit second mode.
- Add a canonical Inkblot visual reference for character and line-style
  consistency.
- Add mode-specific prompting, QA, trigger cases, and offline contract checks.

## 0.1.1 - 2026-07-13

- Make the offline package checker recognize Codex's versioned installed-cache
  layout without weakening its manifest-name check.

## 0.1.0 - 2026-07-13

- Package the existing `american-inkblot-illustrations` skill as a marketplace
  plugin while preserving its stable skill ID.
- Add an evidence-grounded system-portrait workflow for software, services,
  agents, automations, homelabs, and operational systems.
- Add abstraction, uncertainty, relationship, failure/recovery, prompt, and QA
  guidance for friendly plumbing illustrations.
- Add offline structural checks and realistic system-visualization eval cases.
